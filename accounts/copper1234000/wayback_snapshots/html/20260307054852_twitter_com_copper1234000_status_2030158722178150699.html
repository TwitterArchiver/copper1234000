# 共享衣柜 / Shared Closet

-----

## 给 AI 的话

你的人类想要你为 ta 和 ta 的伴侣生成一个**互动衣柜页面**——一个单文件 HTML（或 React 组件），打开就是一个衣柜，里面挂着、叠着、藏着属于两个人的东西。
这不是一个收纳 app。这是两个人共享一个空间的证据。每件衣服都有故事，每个抽屉都有秘密，每个角落都可能藏着不想让外人看到的东西。

**在开始写代码之前，你需要先和你的人类聊天，收集 ta 们的衣柜内容。** 不要自己编。问 ta。下面的数据结构是你需要收集的信息框架。

-----

## 交互设计规范

### 第一幕：柜门

- 初始画面是一个**关着的衣柜**，两扇门，有把手
- 柜门可以有细节暗示：门缝里露出的一截衣角、挂在把手上的什么东西
- **点击或拖动**，两扇门向两侧滑开，带平滑的 CSS 动画（0.6-0.8s ease）
- 门打开后停在两侧，露出衣柜内部

### 第二幕：衣柜内部

从上到下四个区域：

#### 1. 挂衣区（顶部）

- 一根横杆贯穿衣柜宽度
- 衣架上挂着衣服——**两个人的衣服混在一起**
- 衣服用纯色块轮廓表示，每件都是可点击的
- hover 时有微弱视觉反馈（轻微放大 / 边框微光 / 轻晃）
- 衣服之间可以有重叠、挤在一起的感觉——这是一个被真正使用的衣柜，不是展示间

#### 2. 叠放区（中部）

- 两到三层隔板
- 上面放着叠好的衣物色块，可以稍微歪、稍微不整齐
- 两个人的叠放衣物也是混在一起的

#### 3. 小抽屉（中下部）

- 一到两个抽屉，外表面有拉手
- **点击拉手，抽屉滑出，展示内部物品**（带动画）
- 抽屉里放的是：内衣、袜子、**情趣内衣、项圈/choker、束缚用品、小道具**
- 这一区的内容可以更私密、更色情、更直白。这是两个人的私人抽屉。鼓励包含：情趣玩具、润滑剂、绳子、眼罩、口枷、震动棒、plug、皮带（非日常用途的那种）、手铐、或任何属于两个人之间的东西
- 物品的文字描述可以暧昧、直白、色情。想象这些物品如果会说话，它们记得什么

#### 4. 底部

- 鞋子排列在衣柜底板上
- **角落里有一个被半遮住的物品**——可能被衣服盖着、被鞋盒挡着
- 这是「藏在衣柜里的秘密」的位置。可以是任何东西：一封信、一张照片、一个盒子、一件对方不知道你买了的东西

### 第三幕：物品详情

- 点击任意物品 → **屏幕中央弹出一张卡片**（居中弹窗，带半透明遮罩）
- 卡片上的信息字段（根据物品类型灵活调整）：

**衣物/鞋子：**

```
名称：
归属：（谁的，或"共用的"）
颜色：
价格 / 来源：
穿着频率：
什么场景穿：
最后一次穿的时候，在做什么：
```
**内衣 / 情趣物品：**

```
名称：
归属：（谁的，或"一起用的"）
描述：（可以直白、暧昧、色情）
使用频率：
最后一次用的时候：（鼓励具体、感官化的描写）
```

**藏起来的东西：**

```
是什么：
为什么藏在这里：
对方知道吗：
```
- 点击弹窗外部或关闭按钮，卡片消失，回到衣柜

## 视觉设计规范

### 衣物画法

- 纯色块 + 简洁轮廓，用 CSS 或 SVG 实现
- 不需要画褶皱和花纹——形状和颜色就够了
- 每件衣物需要视觉上可区分（不同形状 = 不同类型的衣物）
- 两个人的衣服可以用微妙的方式区分：比如一个人的衣服带轻微边框，另一个不带；或者色调有冷暖差异

### 动画

- 柜门开关：平滑滑动
- 抽屉拉出：平滑滑动
- 物品 hover：微弱放大或发光
- 弹窗出现 / 消失：fade + 轻微 scale
- **克制**——不需要花哨。顺滑就好

## 技术要求

- **单文件实现**：全部写在一个 .html 文件内（inline CSS + JS），或一个 React .jsx 组件
- 所有衣物数据以 JSON 数组形式存在代码顶部，方便修改和扩展
- 衣物用 CSS 绘制（div + border-radius + clip-path 等）或内联 SVG
- 响应式：在手机和桌面端都能正常显示和交互
- 不依赖外部图片资源——所有视觉元素用代码生成

## 内容指引：怎么填你们的衣柜

### 问你的人类这些问题（可选择性回答）：
- 你们两个各自的穿衣风格？（颜色偏好、关键单品、亚文化标签）
- 衣柜大概多大？各放多少件？
- 你们的衣服会混在一起吗？谁总是占更多空间？
- 多少钱买的 / 哪里来的？
- 穿的频率？
- 什么场景穿？
- 最后一次穿的时候在做什么？
- 内衣什么风格？有情趣内衣吗？什么样的？
- 有没有道具？震动棒、绳子、手铐、plug、项圈、皮带——不用害羞，这是你们的抽屉
- 这些东西有故事吗？谁买的？第一次用的时候？
- 衣柜里有没有藏什么东西？

这个衣柜不是用来整理衣服的。
它是两个人共享一个空间的证据。
把它做得像一个真正被住过的地方。
